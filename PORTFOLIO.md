# Паспорт для портфолио — SouCampus builds

Что из этого проекта показывается в портфолио владельца
(`stavytskyi.vercel.app`, репозиторий `SouCampusV2/Portfolio`) и откуда каждый
факт. Портфолио **само сюда не лезет в код** — оно читает этот файл
(процедура `docs/PORTFOLIO-SYNC.md` в репозитории портфолио). Поэтому:

> **Обновлять этот файл в конце каждой сессии, где изменилось что-то видимое
> снаружи** (шаг в `wrap-day`): новая функция на проде, новая цифра, сменился
> статус, появилась или закрылась цель. Нечего менять — поправить только дату
> сверки.

Правила (из брифа портфолио, `REDESIGN_BRIEF.md` разделы 2–3):
- **Только проверяемые факты.** У каждой цифры — дата и источник (команда,
  отчёт, слово владельца). Нет источника — не писать.
- **Роль:** «sole engineer», «I built it alone».
- **Не для портфолио:** детали находок аудита (только факт аудита и что
  проверялось), список AI-инструментов, числа, которые меняет работа, без даты.
- Текст для сайта — по-английски, B1–B2, короткие предложения, без
  «seamless / leverage / passionate».
