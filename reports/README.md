# Еженедельные отчёты

Файлы в этой папке пишет **не человек**, а облачная routine Claude Code —
каждый понедельник в 09:00 по Киеву («Weekly design + structure check»,
https://claude.ai/code/routines).

Что в отчёте: результаты `design-check` и `structure-check` по репозиторию,
пересказ изменений за неделю и разбор терминов, которые в этих изменениях
встретились (владелец учится веб-разработке по ходу проекта).

## Как отчёт попадает в Telegram

Routine его **только коммитит**. Отправить она не может: в её окружении
`api.telegram.org` закрыт сетевой политикой — прокси отвечает `403` на
CONNECT. Выяснено 2026-07-30, до этого отправка молча падала неделями,
а отчёты при этом исправно появлялись здесь.

Доставку делает GitHub Actions — `.github/workflows/report-to-telegram.yml`.
Он срабатывает на любой коммит в `master`, затрагивающий `reports/**`, и
шлёт самый свежий файл документом. Раннеры Actions в интернет ходят
свободно, поэтому там это работает.

Нужны два секрета репозитория: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

Отчёты руками не правим и не удаляем — это архив.
