# 1. Главное: состояние карты одной колонкой

Раньше состояние описывали четыре поля, теперь одно — `state`
(`pending / rejected / live / hidden / suspended / deleted`), а видимость
на витрине считается как **`state = 'live'` И автор в статусе креатора**.
Переписаны все чтения, политики доступа и правило правки. То есть
проверять надо не «новую кнопку», а что ничего не отвалилось.

## 1.1. Витрина и карта

- [ ] `/marketplace` — 10 карт
- [ ] Две с бейджем **Free**, остальные с ценами от €12 до €40
- [ ] Фильтр категорий: Spawns & hubs (2), Buildings (2), Assets (2),
      Adventure, Minigames, Interiors, Landscape — по одной
- [ ] Free-фильтр показывает ровно две карты
- [ ] Поиск по названию и по имени автора находит
- [ ] У пяти карт на карточке стрелки листания скринов, у остальных нет
- [ ] Страница карты открывается, галерея листается, картинка разворачивается
- [ ] Имя автора кликабельно и ведёт на `/creator/soucampus`

## 1.2. Кабинет автора `/resources`

- [ ] Все 10 карт видны, у всех бейдж **Live**
- [ ] «View» ведёт на витрину, «Edit» открывает форму
- [ ] Спрятать карту (⋯ → Hide from the marketplace) → бейдж **Hidden by you**,
      с витрины пропала
- [ ] Вернуть (⋯ → Show in the marketplace) → снова **Live** и снова на витрине
- [ ] Удалить свою карту (⋯ → Delete, ввести название) → пропала из списка,
      пришло уведомление «You deleted …» со ссылкой в поддержку

## 1.3. Админка — каталог `/admin/products`

- [ ] Семь кнопок фильтра: All / Live / In review / Taken down /
      Hidden by author / Rejected / Deleted
- [ ] Каждая показывает то, что обещает; адрес меняется на `?state=…`
- [ ] Плитки сверху: Shown, Live, Taken down, Purchases — числа осмысленные
- [ ] Поиск по названию, slug и автору работает
- [ ] **Take down** с причиной → карта ушла с витрины, бейдж **Taken down**,

- [ ] **Delete** (ввести название) → бейдж **Removed by site**
- [ ] **Restore** у неё → вернулась автору как **Hidden by author**, не на витрину

## 1.4. Кто удалил — новое

Колонка была и раньше, но на экран не попадала: оба случая выглядели
одинаково. Теперь различаются.

- [ ] Карта, удалённая **автором** → в каталоге бейдж **Deleted by author**
      (серый), под причиной подпись «Deleted by the author:»
- [ ] Карта, удалённая **из админки** → бейдж **Removed by site** (красный),
      подпись «Removed by the site:»
- [ ] На `/admin` внизу две плитки: **Deleted by authors** и **Removed by site**,
      числа сходятся с каталогом
- [ ] Клик по плитке ведёт в каталог с уже выбранным фильтром Deleted

## 1.5. Переходы, которые стережёт база

- [ ] Правка **снятой** карты (Take down → автор жмёт Edit → Save) → ушла в
      очередь `/admin/moderation` с тегом «Back after a takedown»
- [ ] Там же видна причина, за что снимали (она НЕ стирается)
- [ ] После Approve карта на витрине, плашка у автора пропала
- [ ] Правка **отклонённой** карты → снова в очередь, прошлый вердикт стёрт
- [ ] Замена файла у **живой** карты → она ушла с витрины в очередь
- [ ] Удалённую карту автор не может ни спрятать, ни вернуть — внятный текст,
      а не «not found»

## 1.6. Дыра, которую закрыли ⬅ самое важное

Лишённый статуса креатор мог вернуть свои карты на витрину запросом из
консоли браузера. Проверить, что больше нельзя: залогинься своим
аккаунтом, открой консоль на сайте и выполни

```js
await supabase.from('products').update({ creator_active: true }).eq('creator_id', ТВОЙ_ID)
```

- [ ] Запрос проходит без ошибки, но в базе `creator_active` **не изменился**
      (триггер молча вернул старое значение)
- [ ] То же самое с `state`: `update({ state: 'live' })` на карте в очереди
      ничего не меняет

## 1.7. Отзыв статуса креатора

- [ ] **Revoke** предлагает шаблоны причин чек-боксами + поле «дописать»
- [ ] Без выбранного пункта и без текста кнопка неактивна
- [ ] Виден предпросмотр текста, который придёт человеку
- [ ] После отзыва все живые карты пропали с витрины **сразу**
- [ ] В каталоге у них бейдж **«Creator revoked»**, а не «Taken down»
- [ ] У автора на `/resources` бейдж **«Paused»** и подпись, что дело в доступе

- [ ] В уведомлении названо число снятых карт
