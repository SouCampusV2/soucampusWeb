## 1. Загрузка карты

Меню профиля → **Your resources** → «Add your first map» (или `/creator/upload`).

- [ ] Несколько фото загружаются, перетаскиванием меняется порядок
- [ ] Звёздочка на миниатюре назначает обложку
- [ ] Описание: жирный, курсив, заголовки, списки, ссылка
- [ ] **Картинка внутри описания** — кнопка с иконкой картинки в панели
- [ ] **Таблица** внутри описания
- [ ] Категория — выпадающий список, восемь вариантов
- [ ] Файл карты прикрепляется
- [ ] Кнопка при отправке показывает стадии: Uploading map file → Uploading images → Saving
- [ ] После отправки — страница «Submitted for review»

**Проверки, которые должны НЕ пропустить:**
- [ ] Файл больше 15 МБ → отказ с понятным текстом
- [ ] Картинка больше 5 МБ → отказ
- [ ] Несколько картинок суммарно больше 30 МБ → отказ
- [ ] Переименовать любой `.txt` в `.zip` и попробовать загрузить → отказ
- [ ] Файл `.schem` и `.schematic` принимаются (были только .zip)
