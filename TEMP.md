## Инструкция: проверки из консоли ⬅ ты просил

В прошлом списке шесть пунктов упирались в «не знаю, какой ID и где брать».
Вот один рецепт на все.

**Зачем они вообще.** Все эти проверки спрашивают одно: держится ли запрет
**в базе**, а не в форме. Спрятанное поле, серая кнопка и блокировка ввода
защищают ровно ноль — запись идёт из браузера прямо в базу, нашего кода в
этом пути нет. За 20–21 августа это выяснялось пять раз подряд.

**Шаг 1 — свой ID и токен.** На сайте, будучи вошедшим, F12 → Console.
Первый раз браузер попросит напечатать `allow pasting` — это нормально,
напечатай и нажми Enter.

```js
const key = Object.keys(localStorage).find(k => k.startsWith('sb-') && k.endsWith('-auth-token'));
const s = JSON.parse(localStorage.getItem(key));
console.log('ID:', s.user.id);
console.log('token:', s.access_token);
```

**Шаг 2 — ключ `apikey`.** DevTools → **Network** → обнови страницу карты →
найди любой запрос к `...supabase.co/rest/v1/...` → Headers → скопируй
значение заголовка `apikey`. Он публичный, это не секрет.

**Шаг 3 — сама проверка.** Дальше любой пункт вида «нельзя записать» делается
так (пример: попытка поставить себе галочку):

```js
const API = 'https://ТВОЙ-РЕФ.supabase.co/rest/v1';
const anon = 'ВСТАВЬ_APIKEY';
const r = await fetch(`${API}/profiles?id=eq.${s.user.id}`, {
  method: 'PATCH',
  headers: {
    apikey: anon,
    Authorization: `Bearer ${s.access_token}`,
    'Content-Type': 'application/json',
    Prefer: 'return=representation',
  },
  body: JSON.stringify({ is_verified: true }),
});
console.log(r.status, await r.json());
```

**Как читать ответ — тут есть тонкость, и она важна.** Правильных исходов
**два**, и они значат разное:

- **Ошибка прав (401/403)** — запрет стоит политикой. Записать нельзя вовсе.
- **`200` и пустой массив `[]`, или `200` со СТАРЫМ значением** — запрет
  стоит триггером, это **молчаливый откат**. Запрос прошёл, но база вернула
  значение на место. Так сделано намеренно у `is_verified`, `is_founder`,
  `submissions_blocked_until`: иначе сохранение всего профиля падало бы
  из-за поля, которого человек в форме не видит.

⚠️ **Опасен только третий исход:** `200` и **новое** значение. Это дыра.
