# SouCampus builds — план и статус

Название сайта: **SouCampus builds** (https://soucampus.online). Портфолио студии
Minecraft-построек + магазин карт (маркетплейс, креаторство открыто 27.10) + обучение
владельца веб-разработке.

**Этот файл держит только открытое: статус, очередь, вопросы.** Он грузится в каждую
сессию, поэтому короткий (сокращён 03.11 с 1884 строк). Закрытое не удаляется, а
уходит в архив — правило в `docs/RULES.md` → «Документация». Полная прежняя версия со
всеми разборами и датами — [`docs/archive/CLAUDE-2026-07-to-11.md`](docs/archive/CLAUDE-2026-07-to-11.md).

## 🚦 Легенда статусов (одна на всю документацию)

| | Значение |

## 🧭 Фаза работы и обучение

**Фаза (решения 27.07 и 17.08):** новых фич мало, доводка; порядок —
**безопасность → платежи → всё остальное**. Подробно — `ROADMAP.md`.

**Обучение — постоянная колея, а не пункт очереди** (решение 17.08). Решения о
продукте у владельца на уровне mid, код руками — ниже junior, причина — часы. Поэтому
в каждой сессии: **объяснять до кода**, а не после; «работает» — не объяснение;
держать границу «решает база / решает код»; мелкие безопасные правки отдавать
владельцу в руки. Программа — `IDEAS.md` → «Обучение», следующий блок — разбор кода
Этапа 3, затем RPC vs REST.

## 🗺️ Что есть на сайте — коротко

- **Стек:** Next.js 16 (App Router) + TypeScript + Tailwind v4, Supabase (Postgres, Auth,
  Storage, Realtime), Stripe (тест), Motion, Tiptap, Vitest. Версии — `package.json`.
- **Деплой:** пуш в `master` = прод (Vercel), `dev` = preview
  `https://soucampus-builds-git-dev-sou-campus.vercel.app`. CI — lint + build + тесты.
- **Страницы и маршруты** — `STRUCTURE.md` § 6. Публичное — в группе `src/app/(site)/`,
  админка — `src/app/admin/` вне группы (гейт в proxy, layout и обработчике; постороннему 404;
  с привязанным приложением-аутентификатором нужен ещё и код — `lib/admin.ts`).
- **Профиль** живёт на `/@<username>`, в файлах это `/u/[username]` (rewrite) — `revalidatePath`
  принимает `/u/…`.
- **Контент как данные:** портфолио и отзывы — в базе; Wiki, What's new, FAQ, юридическое —
  в `src/lib/*.ts`.
- **Плейсхолдер:** фото автора на `/about` нет (заглушка убрана 24.09).
