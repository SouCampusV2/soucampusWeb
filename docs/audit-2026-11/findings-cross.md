## Находки

### X-01 · 🔴 Высокая · «Злой креатор»: непросмотренный файл доходит до покупателей тремя путями

Главный сквозной вопрос плана. Креаторство открыто с 27.10, сканер не запущен,
единственная защита покупателя от содержимого файла — ваш просмотр в очереди
(инвариант 19). Ниже — всё, чем креатор может навредить, по каналам. Подробности
каждой строки — в `findings-site.md` под указанным номером.

**Файл.** Ваш просмотр обходится тремя независимыми способами:

| Путь | Номер | Что нужно сделать креатору |
|---|---|---|
| Спрятать карту → заменить файл → вернуть | S-13 | три нажатия, очередь не узнаёт |
| Заменить файл у проданной карты | S-01 | одно сохранение; прежние покупатели получают новый файл сразу, даже если вы отклоните правку |
| Подменить файл, пока карта в очереди | S-17 | сохранить правку между вашим просмотром и нажатием Approve |

Плюс: остановить раздачу уже найденного вредного файла нечем (S-02), а
автоматическая проверка, которая на этих путях всё-таки срабатывает, — чёрный
список с пробелами (S-23).

**Описание и картинки.** После одобрения правятся без проверки: ссылка на внешний
файл под одобренной картой (S-18), картинка-счётчик с чужого сервера и порча
журнала скачиваний (S-21).

**Цена.** Меняется на живой карте свободно; на оплаченные заказы не влияет. Цена
1–49 центов ломает покупку (S-09). В живом режиме деньги за чужую платную карту
придут вам, механизма выплаты нет (S-12).

**Отзывы и продажи.** Оценка собственной карты, «покупка» у самого себя, вторые
аккаунты (S-05, S-20).

**Ник и профиль.** Закрыто: набор символов ограничен, зарезервированные имена
заняты, ссылки профиля проверяет база, права через профиль не назначить.

**Discord-пост.** Витрину публикует админ из админки; креатор туда не пишет.
Через бота — поддельный отзыв с чужого сервера (B-01 в `findings-bot.md`).

**Хранилище.** Публичный хостинг непроверенных файлов (S-19) — доступен даже не
креатору.

- **Что получает:** доставку произвольного файла покупателям под вашим брендом,
  минуя единственную работающую проверку.
- **Как чинить (порядок):** сначала S-13 и S-17 — это правки в несколько строк,
  закрывающие обход для новых покупателей. Затем S-01 + S-02 одной миграцией
  (колонка одобренного файла и признак блокировки) — это закрывает тему
  структурно: покупателю отдаётся только то, что одобрено. Затем S-18.
  До этого — не одобрять заявки новых креаторов или считать каждую живую карту
  чужого креатора непроверенной после любой её правки (запрос в `checks.sql`,
  раздел 13, показывает такие карты).
- **Цена правки:** первые две — мелочь; структурная — день и миграция на обеих базах.

### X-02 · 🟡 Низкая · Один `VIEW_HASH_SALT` на три обязанности и две среды

- **Где:** `src/app/api/view/route.ts` (подпись cookie посетителя и хэш IP),
  `src/app/api/download/route.ts` (хэш IP в журнале скачиваний).
- **Суть:** одной строкой подписывается cookie `scv_visitor` и солятся хэши IP в
  двух таблицах. IPv4-адресов четыре миллиарда: зная соль, все хэши IP
  перебираются за минуты, то есть «мы не храним IP» перестаёт быть правдой для
  того, кто получил соль и таблицу. Preview — среда, где ключи живут свободнее
  (ветки, панель, логи сборок); соль там та же, что на проде.
- **Как чинить:** отдельное значение для прода (в тех-долге `CLAUDE.md` это уже
  записано) и отдельная переменная для подписи cookie. При смене соли старые хэши
  перестают сравниваться с новыми — для журнала скачиваний записать дату смены.
- **Цена правки:** мелочь.

### X-03 · 🟡 Низкая · Сканер, бот и его секреты — на одном VPS

- **Суть:** сканер будет разбирать файлы, присланные незнакомыми людьми, с помощью
  ClamAV — программы с длинной историей уязвимостей в разборе форматов. Рядом на
  том же сервере лежит `.env` бота с токеном Discord и секретом моста и база
  заказов. Взлом самого рискованного сервиса не должен отдавать соседа.
- **Как чинить:** отдельный пользователь системы и отдельная папка для каждого
  compose-проекта, права `600` на оба `.env`, никакого `docker.sock` в
  контейнерах, файрвол; подробный список — H-04 в `findings-scanner.md`. При
  росте — отдельный самый дешёвый VPS под сканер.
- **Цена правки:** час при деплое сканера.

### X-04 · ℹ️ Заметка · CI, зависимости, `.env.example`

- **`.github/workflows` сайта:** права токена — только чтение; `pull_request`, а не
  `pull_request_target` (секреты чужим веткам не выдаются); служебного ключа в CI
  нет. Сторонних actions нет — только `actions/checkout@v4` и `setup-node@v4`,
  закреплены по тегу, а не по хэшу; для официальных это приемлемо.
- **Отчёт в Telegram:** токен в адресе запроса `curl`, в лог выводится только
  ответ Telegram — токена в нём нет.
- **`npm audit --omit=dev`** на 10.11: сайт — 0, бот — 0. Dev-инструменты сайта —
  находки есть, на сайт не попадают (известно). Сканер — только Spring Boot 4.1.2,
  проверить актуальность перед деплоем.
- **`.env.example` сайта отстал:** нет `DISCORD_BRIDGE_SECRET`, четырёх
  `DISCORD_*_WEBHOOK_URL`, `SCANNER_URL`, `SCANNER_SECRET`. Кто разворачивает
  проект по примеру, получит сайт, где эти части молча выключены.
- **Блок J (Axiom-мод) не пройден** — см. `findings-axiom.md`.
