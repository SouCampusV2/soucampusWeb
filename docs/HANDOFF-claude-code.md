# Передача в Claude Code

Что забрать из разговора о бизнес-плане в работу над кодом. Полный контекст —
в `docs/BUSINESS.md`; здесь только то, что превращается в задачи.

Порядок работ на ближайшие месяцы: **безопасность → платежи → всё остальное.**
Разработка новых функций маркетплейса заморожена.

---

## 1. Заблокировать креаторство

Решение владельца 19.08: приём чужих авторов откладывается на пару месяцев.

- Закрыть **флагом, не удалением кода**. Механика заявок, модерации, профилей
  авторов остаётся в репозитории и работает — вход закрыт.
- Заявку на статус креатора убрать из интерфейса или показывать как «скоро».
- Проверить, что при закрытом флаге ничего не ломается: очередь модерации,
  отзыв статуса, витрина авторов.

Причина, если понадобится: дефицит не в авторах, а в трафике. Автор идёт
туда, где продаётся. Пока трафика нет, впуск авторов создаёт обязательство
(выплаты), которое нечем выполнить.

## 2. Безопасность — до живых платежей

- Google-аутентификация (OAuth).
- Двухфакторная аутентификация.
- Проверка загружаемых файлов на вредоносность.
- Ограничение частоты запросов (rate limiting).
- Аудит безопасности.

Живые платежи Stripe включать **только после** этого. Решение из брифинга
(раздел 4), подтверждено.

## 3. Каталог

- **Убрать или скрыть 10 карт без файлов.** Сейчас это наполнение для вида:
  цены и картинки есть, скачивать нечего. При включении живых платежей это
  превращается в приём денег за несуществующий товар.
- Маркетплейс не индексируется, пока нет настоящего товара — решение
  остаётся в силе.

## 4. Страница товара: чего не хватает

По итогам разбора рынка карточка товара должна нести спецификацию для
администратора сервера, а не описание красот. Проверить, есть ли поля под:

- размер карты в блоках, версия Minecraft
- количество мест под NPC, под крейты, под варпы
- доля карты со светом
- что входит: интерьеры, фермы, схематики, WorldEdit-файлы
- предупреждения при установке (например `/gamerule randomTickSpeed 0`)
- обложка-рендер отдельно от галереи скриншотов (10-12 штук)
- блок отзывов с просьбой оставить отзыв после покупки

Цена в каталоге: **$9–12**, отдельные позиции выше. Прежний ориентир $5 снят.

## 5. Бесплатные карты

Появляется новая сущность: карта с ценой 0, которая работает воронкой.
Проверить, поддерживает ли текущая схема бесплатный товар — оплата, «мои
покупки», скачивание без Stripe.

## 6. Выплаты авторам — исследовать, не строить

Механизма нет вовсе. Пока креаторство заблокировано — не горит, но к моменту
разблокировки нужно решение. Смотреть **Tebex** (BuiltByBit выплаты не строил
сам, а взял партнёра) прежде, чем Stripe Connect. Вопрос к проверке: берёт ли
Tebex сторонние площадки.

## 7. Хостинг — возможная экономия €45/мес

Пока живых платежей нет и маркетплейс закрыт, проверить, допустимы ли
бесплатные тарифы Vercel и Supabase. Vercel Hobby запрещает коммерческое
использование — вопрос, считается ли им сайт-портфолио с приёмом заказов.
При нулевом бюджете это реальные деньги. Решение — по правилам Vercel, не
по догадке.

## 8. Вопросы «а это вообще возможно»

Собрать ответы и принести обратно в разговор о плане:

- Сколько времени займёт Google-аутентификация и 2FA на текущем стеке.
- Можно ли закрыть креаторство одним флагом без переписывания.
- Что конкретно входит в «аудит безопасности» и сколько это дней.
- Поддерживает ли схема бесплатные товары без обхода Stripe.
- Что нужно, чтобы Discord-бот выдавал роли покупателям с сайта.
